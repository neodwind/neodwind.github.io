사과가쿵 제작기 · Sagwaga Kung Studio

사과가쿵 제작기는 운영자 본인이 직접 만든 영상을 운영자 본인의 유튜브 채널(유리의 부엌 · 아기판다 하트판)과 인스타그램 계정에 올리고, 공개 시각을 예약하고, 조회수 같은 채널 통계를 확인하기 위해 쓰는 개인용 제작 도구입니다. 일반 사용자에게 제공하는 서비스가 아니며, 운영자 한 사람만 사용합니다.

Sagwaga Kung Studio is a personal production tool used only by its owner to upload the owner's own videos to the owner's own YouTube channels and Instagram account, schedule their publication, and read basic channel statistics. It is not offered to the public.

하는 일 · What it does

  • 운영자 PC에서 만든 영상을 운영자 채널에 업로드하고 제목·설명·공개 예약을 설정 / Uploads the owner's videos to the owner's channels and sets titles, descriptions and scheduled publishing
  • 운영자 채널의 영상 목록과 조회수·시청 시간 등 통계 확인 / Reads the owner's video list and channel analytics
  • YouTube Data API와 YouTube Analytics API를 사용합니다 / Uses the YouTube Data API and YouTube Analytics API (YouTube API Services)
