개인정보처리방침 · Privacy Policy

사과가쿵 제작기 · Sagwaga Kung Studio

사과가쿵 제작기(이하 "이 도구")는 운영자 본인만 사용하는 개인용 도구입니다. 이 방침은 이 도구가 구글 계정 연결(OAuth)로 접근하는 정보를 어떻게 다루는지 설명합니다.

Sagwaga Kung Studio ("the Tool") is used only by its owner. This policy explains how the Tool handles information it accesses through Google sign-in (OAuth).

1. 접근하는 정보 · Information accessed

  • 운영자 유튜브 채널의 기본 정보(채널 이름·ID), 영상 목록, 영상 제목·설명·공개 설정 / The owner's YouTube channel info, video list and video metadata
  • 운영자 채널의 조회수·시청 시간 등 통계 / The owner's channel analytics
  • 구글 계정 연결 토큰(접근 토큰·갱신 토큰) / OAuth access and refresh tokens

2. 사용 목적 · How it is used

운영자 본인의 영상을 업로드·예약하고, 운영자 본인 채널의 통계를 확인하는 데에만 씁니다. 광고, 판매, 프로파일링에는 쓰지 않습니다.

Only to upload and schedule the owner's own videos and to read the owner's own channel statistics. Never for advertising, sale or profiling.

3. 저장과 보관 · Storage

연결 토큰과 결과 기록은 운영자 PC에만 저장되며, 외부 서버로 보내지 않습니다. 운영자가 파일을 지우면 즉시 삭제됩니다.

Tokens and logs are stored only on the owner's own computer and are never sent to any other server. They are deleted when the owner deletes those files.

4. 제3자 제공 · Sharing

이 도구가 받은 정보는 누구에게도 제공·판매·공유하지 않습니다. 정보는 구글(YouTube API 서비스)과의 통신에만 쓰입니다.

The Tool does not share, sell or transfer any data to anyone. Data is exchanged only with Google through YouTube API Services.

5. 연결 해제 · Revoking access

언제든지 구글 계정 → 보안 → 서드 파티 앱 및 서비스에서 이 도구의 접근 권한을 해제할 수 있습니다.

Access can be revoked at any time at Google security settings.

6. YouTube API 서비스 · YouTube API Services

이 도구는 YouTube API 서비스를 사용합니다. 이용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

The Tool uses YouTube API Services. By using it you are bound by the YouTube Terms of Service, and the Google Privacy Policy applies.
